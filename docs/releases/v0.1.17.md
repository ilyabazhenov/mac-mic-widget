## Mac Mic Widget v0.1.17

This patch release improves menu bar visibility resilience in installed builds and adds release-time startup validation.

### Highlights
- Improved status item fallback: when symbol rendering is unavailable or invalid, the app now shows a visible `Mic` label and switches to variable status item width.
- Added a packaging smoke-check in `scripts/release/package_release.sh` that launches the bundled app executable in safe mode and verifies process startup.

### Requirements
- macOS 14+
- Apple Silicon (arm64) build

### Known limitations
- This release is distributed as an unsigned build and may require Gatekeeper approval on first launch.
- Some USB/Bluetooth headsets expose input gain in non-standard ways and may not support write via CoreAudio scalar property.
- App reads/writes the system default input device only.
