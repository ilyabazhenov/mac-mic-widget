## Mac Mic Widget v0.1.16

This patch release improves startup reliability on systems where the status icon can fail to render.

### Highlights
- Added a status item title fallback (`Mic`) when SF Symbol rendering is unavailable, so the menu bar control remains visible and clickable.
- Kept native template icon rendering as the primary path without changing default interaction behavior.

### Requirements
- macOS 14+
- Apple Silicon (arm64) build

### Known limitations
- This release is distributed as an unsigned build and may require Gatekeeper approval on first launch.
- Some USB/Bluetooth headsets expose input gain in non-standard ways and may not support write via CoreAudio scalar property.
- App reads/writes the system default input device only.
