## Mac Mic Widget v0.1.15

This release refreshes the app icon pipeline and improves menu bar visual feedback consistency.

### Highlights
- Replaced the bundled app icon with a new light system-style microphone and input-level meter design.
- Added `assets/AppIcon.source.png` and `scripts/generate_app_icon.sh` to regenerate the PNG iconset and `AppIcon.icns`.
- Refined menu bar status item rendering to use native template behavior with improved visual-level mapping.

### Requirements
- macOS 14+
- Apple Silicon (arm64) build

### Known limitations
- Some USB/Bluetooth headsets expose input gain in non-standard ways and may not support write via CoreAudio scalar property.
- App reads/writes the system default input device only.
