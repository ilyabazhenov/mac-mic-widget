# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current AppIcon with a reproducible `System Capsule Mic` icon while preserving the existing status bar SF Symbol behavior.

**Architecture:** Use a generated raster source image, downsample it into the existing `.iconset` sizes, and rebuild the `.icns` bundle with `iconutil`. Keep runtime Swift code unchanged.

**Tech Stack:** PNG assets, `sips`, `iconutil`, Swift Package Manager tests.

---

**Files:**

- Create: `scripts/generate_app_icon.sh`

- [ ] **Step 1: Add the generated source image**

- [ ] **Step 2: Run the generator**
